# no-plan.app

Marketing page for the noplan iOS app. React + Vite + React Router, deployed to https://no-plan.app.

```bash
pnpm install
pnpm dev      # local dev server
pnpm build    # production build → dist/
pnpm lint
```

Routes: `/` (product page), `/post` (1200×627 canvas for screenshotting a social post).
Moved from adameniia.com/noplan. Page content lives in `src/pages/NoPlan.jsx`; styles in `src/css/noplan.css`.
